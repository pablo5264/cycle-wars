# APK Build Troubleshooting

Use this guide when `gradlew.bat assembleRelease` fails or produces an APK that does not launch.

## Build Command

Run from `apps/mobile/android`:

```cmd
set "NODE_ENV=production"
set "JAVA_HOME=C:\Program Files\Android\Android Studio\jbr"
set "ANDROID_HOME=C:\Users\Pablo\AppData\Local\Android\Sdk"
set "ANDROID_SDK_ROOT=C:\Users\Pablo\AppData\Local\Android\Sdk"
set "PATH=%JAVA_HOME%\bin;%ANDROID_HOME%\platform-tools;%ANDROID_HOME%\emulator;%PATH%"
gradlew.bat clean assembleRelease
```

Expected APK:

```text
apps/mobile/android/app/build/outputs/apk/release/app-release.apk
```

## Capture A Build Log

```cmd
gradlew.bat clean assembleRelease --stacktrace --info > build-error.txt 2>&1
notepad build-error.txt
```

Attach or paste the first real error above `BUILD FAILED`.

## Common Failures

### Maven Or Dependency Download Failure

Symptoms:

- `Could not GET https://repo.maven.apache.org`
- `Host desconocido`
- `Could not download react-android`
- `Could not download hermes-android`

Fix:

- Confirm the PC has internet access.
- Retry after DNS or network recovers.
- Avoid offline builds until Gradle dependencies are already cached.

### Metro Cannot Find Entry File

Symptoms:

- `Unable to resolve module ./index.ts`
- Metro searches from the wrong project root.

Fix:

- Build from `apps/mobile/android`.
- Confirm `apps/mobile/index.ts` exists.
- Use the Expo/React Native config already generated by the mobile app.

### Missing React Native CLI

Symptoms:

- `react-native depends on @react-native-community/cli`
- `No Metro config found`

Fix:

- Run `npm.cmd install` from the repository root.
- Do not install random packages inside `apps/mobile/android`.

### Java Or SDK Not Found

Symptoms:

- `JAVA_HOME is not set`
- `SDK location not found`
- `adb is not recognized`

Fix:

- Re-run the environment variable block from `docs/ANDROID_DEVICE_SETUP.md`.
- Confirm Android Studio's bundled JBR exists.
- Confirm `C:\Users\Pablo\AppData\Local\Android\Sdk\platform-tools\adb.exe` exists.

## After A Successful Build

Install and launch using `docs/ANDROID_DEVICE_SETUP.md`.

If the app installs but crashes, capture logs with `adb logcat` and record the run in `docs/MOBILE_QA_REPORT.md`.
